How to preview:
Open index.html in a web browser.

Before publishing:
1. Replace placeholder gradient artwork panels with actual artwork images.
2. Confirm the contact email. The current site uses info@msbart.com exactly as requested.
3. Replace Instagram and X placeholder links with the real profile URLs.
4. Connect forms to a service such as Formspree, Airtable, Google Forms, or a custom backend.
5. Confirm competition dates, rules, eligibility, jurors, awards, fees, and privacy terms.
6. Connect marketplace listings to an inquiry or checkout system.
